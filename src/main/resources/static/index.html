Hwan Coupon Demo

백엔드 시연용 최소 화면

기본 기능 시연과 핵심 테스트를 한 화면에서 바로 볼 수 있게 정리한 데모입니다. 관리자는 쿠폰 생성/배치 요청을, 사용자는 발급/조회/사용을, 핵심 테스트는 동시성/비동기 흐름을 한 번에 확인합니다.

추천 시연 순서

1

관리자 계정으로 로그인한 뒤 선착순 쿠폰 예시 또는 대량 발급 쿠폰 예시를 고릅니다.

2

쿠폰 생성을 누르면 생성된 쿠폰 ID가 아래 발급 입력칸으로 자동 반영됩니다.

3

일반 사용자 계정으로 로그인한 뒤 선착순 발급, 내 쿠폰 조회, 쿠폰 사용을 테스트합니다.

4

핵심 강점을 보고 싶으면 선착순 동시성 테스트나 대량 발급 빠른 테스트를 누르면 됩니다. 쿠폰과 테스트 유저를 자동 생성합니다.

1. 관리자 준비

ADMIN 전용

쿠폰 생성, 쿠폰 목록 조회, 대량 발급 요청, 빠른 핵심 테스트는 관리자 로그인 상태에서만 사용합니다.

선착순 발급 버튼을 테스트하려면 FIRST_COME, 대량 발급 요청을 테스트하려면 ADMIN_ISSUED 쿠폰을 생성해야 합니다.

선착순 동시성 테스트는 새 FIRST_COME 쿠폰과 테스트 유저를 자동 생성한 뒤 서버 내부에서 병렬 요청을 실행합니다. 기대 결과는 issuedRows == couponQuantity, successCount == couponQuantity, 나머지는 COUPON_EXHAUSTED입니다.

회원가입 응답이나 DB에서 확인한 실제 사용자 ID를 넣어야 합니다. 존재하지 않는 ID는 발급되지 않습니다.

2. 사용자 시연

USER 전용

선착순 발급 버튼은 일반 사용자로 로그인한 상태에서, 관리자가 미리 만든 쿠폰 ID를 입력하고 누르는 버튼입니다.

1) 관리자가 생성한 쿠폰 ID를 입력하고 2) 일반 사용자로 로그인한 뒤 3) 선착순 발급을 누르면 됩니다. 주문 금액은 쿠폰 사용 시 최소 주문 금액 검증에 쓰입니다.
